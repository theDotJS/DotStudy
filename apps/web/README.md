# apps/web

Frontend do DotStudy. Next.js + TypeScript + Tailwind. Roda na porta 3000.

Setup, comandos e pré-requisitos: **[README da raiz](../../README.md)**.

| Pasta                | O que é                                                                  |
| -------------------- | ------------------------------------------------------------------------ |
| `src/app/`           | Rotas. `/login`, `/cadastro`, `/mapa`, `/nivel/[id]` ainda estão vazias. |
| `public/prototipos/` | HTML e CSS em uso até o HTML final existir. Ver o `LEIA-ME.md` de lá.    |

Antes de escrever tela que fala com a API, leia [`docs/contrato-api.md`](../../docs/contrato-api.md).
